# TonConnect manifest

This repository hosts a TonConnect manifest for one of my TON Telegram mini-apps.

TonConnect requires the manifest to live at a public, stable URL so wallets (Tonkeeper, Tonhub and others) can read the app name, icon and return URL before a user approves the connection.

- `manifest.txt` — the manifest served to wallets

> ⚠️ This manifest is live — a running app depends on it. Please don't rename or delete the file.
